# Dirt MCP documentation

- [`vision.md`](vision.md) defines the product and v1 boundaries.
- [`architecture.md`](architecture.md) defines component ownership and runtime
  behavior.
- [`v1-design.md`](v1-design.md) summarizes implemented tool behavior and
  editing semantics.

The implemented Java-to-TypeScript interface is always described by
[`../protocol/openapi.yaml`](../protocol/openapi.yaml). Design documents do not
make an endpoint available; code, contract, and tests must land together.
